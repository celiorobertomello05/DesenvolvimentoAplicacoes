# Aula 06 — Encapsulamento

**Assunto:** classe `Produto` com atributos privados (`_nome`, `_valor`, `_quantidade`), getters, setters com validação e `try/catch` para tratar valores inválidos.

- `produto_getters_setters/`: exercício feito em aula.
- `app_produtos/`: versão final, com getters em arrow function e todos os setters validados.

## Como rodar

```bash
cd app_produtos
dart pub get
dart run
```
