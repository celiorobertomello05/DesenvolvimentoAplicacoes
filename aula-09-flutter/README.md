# Aula 09 — Flutter

**Assunto:** primeiros aplicativos com Flutter (widgets, estado e pacotes).

| App | O que faz |
|-----|-----------|
| [relogio_digital](relogio_digital) | Relógio digital que atualiza a cada segundo (`StatefulWidget` + `Timer`) e seletor de data em português. |
| [dado_da_sorte](dado_da_sorte) | Atividade de completar o código de um dado: pratica os tipos de função do Dart (arrow, getter, `async/await`, callback, anônima). |
| [desafio_7_dias](desafio_7_dias) | Lista de desafios para cada dia da semana, com criar, editar, concluir e adicionar ao calendário do celular. |

## Como rodar

```bash
cd relogio_digital
flutter pub get
flutter run
```
