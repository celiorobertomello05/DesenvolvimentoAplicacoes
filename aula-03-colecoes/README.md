# Aula 03 — Coleções

**Assunto:** coleções do Dart e mutabilidade.

- `list_set_map.dart`: `List` (lista com índice), `Set` (ignora repetidos) e `Map` (chave → valor).
- `mutabilidade.dart`: diferença entre `var` (pode reatribuir), `final` (não reatribui) e `const` (não muda o conteúdo), além de listas `dynamic`.

## Como rodar

```bash
dart run list_set_map.dart
dart run mutabilidade.dart
```
