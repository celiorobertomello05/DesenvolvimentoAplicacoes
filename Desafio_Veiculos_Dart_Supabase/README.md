# Desafio — Cadastro de Veículos (Dart + Supabase)

**Assunto:** cadastro de veículos de uma concessionária, acessível pelo terminal. Um menu em `while` permite cadastrar, listar, atualizar e excluir veículos no Supabase, tudo numa única execução.

## Organização

| Arquivo | Responsabilidade |
|---|---|
| `bin/main.dart` | Exibe o menu, lê e valida as entradas, chama os métodos e mostra os resultados |
| `lib/conexao.dart` | Carrega o `.env` e disponibiliza a função `conectar()` |
| `lib/veiculos.dart` | `cadastrarVeiculo`, `listarVeiculos`, `atualizarVeiculo`, `excluirVeiculo` |
| `.env` | `SUPABASE_URL` e `SUPABASE_PUBLISHABLE_KEY` (não vai para o GitHub) |

## Como configurar a conexão

1. Copie o arquivo `.env.example` para `.env`.
2. No Supabase, abra **Project Settings → API** e copie a URL do projeto e a chave **publishable**.
3. Preencha o `.env`:

```
SUPABASE_URL=https://seu-projeto.supabase.co
SUPABASE_PUBLISHABLE_KEY=sua-chave-publica
```

## Tabela no Supabase

No **SQL Editor**, execute:

```sql
create table veiculos (
  id bigint generated by default as identity primary key,
  marca varchar(50) not null,
  modelo varchar(100) not null,
  ano integer not null,
  valor decimal(12, 2) not null,
  quilometragem integer not null
);

-- Permissão para a chave publishable (papel anon)
grant select, insert, update, delete on public.veiculos to anon;

-- RLS ligado, com regra liberando o acesso (não há login neste exercício)
alter table public.veiculos enable row level security;

create policy "acesso_publico_veiculos"
on public.veiculos
for all
to anon
using (true)
with check (true);
```

## Como executar

Na raiz do projeto:

```bash
dart pub get
dart run bin/main.dart
```
