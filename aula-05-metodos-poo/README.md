# Aula 05 — Métodos em POO

**Assunto:** classe `Roupa` com métodos que alteram o estoque (`incrementar` / `decrementar`), cálculo do valor total e uso do `this`.

- `bin/meu_app.dart`: versão com construtor de parâmetros nomeados.
- `bin/roupa_construtor_posicional.dart`: primeira versão, com construtor de parâmetros posicionais.

## Como rodar

```bash
dart pub get
dart run bin/meu_app.dart
dart run bin/roupa_construtor_posicional.dart
```
