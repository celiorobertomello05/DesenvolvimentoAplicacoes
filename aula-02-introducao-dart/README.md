# Aula 02 — Introdução ao Dart

**Assunto:** primeiros passos com Dart no terminal.

- `bin/meu_app.dart`: variáveis e tipos (`int`, `double`, `String`, `bool`), interpolação de texto e diferença entre `var` e `dynamic`.
- `bin/entradaDados.dart`: leitura de dados do teclado com `stdin.readLineSync()` e conversão com `int.parse` / `double.parse`.

## Como rodar

```bash
dart pub get
dart run bin/meu_app.dart
dart run bin/entradaDados.dart
```
