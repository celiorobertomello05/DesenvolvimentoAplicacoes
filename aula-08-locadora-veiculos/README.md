# Aula 08 — Atividade: Locadora de Veículos

**Assunto:** sistema de locadora no terminal que junta os conteúdos de POO:

- classe abstrata `Veiculo` com encapsulamento e validação nos setters;
- subclasses `Carro` e `Moto` (herança);
- menu para cadastrar, listar, editar, excluir e alugar veículos, com leitura validada do teclado.

## Como rodar

```bash
dart pub get
dart run bin/main.dart
```
